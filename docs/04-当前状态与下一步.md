# 当前状态与下一步

## 当前可用

- `extract` / `learn` / `assets` / `template-add` / `template-list` / `build` / `render` 全部可用。
- 模板模式端到端验证通过：以 `工作汇报.pptx` 为模板生成 5 页，项目文件夹含 `deck.pptx` 与 `preview/`。
- 模板库可用：导入「红色工作汇报」，按 `templateName` 引用生成成功。
- 自由版式仍可用：`output` 指向 `.pptx` 时单文件输出正常。
- 自由版式（v0.1.1）：默认不输出任何英文固件（页脚、封面 eyebrow/badge 均可选，默认为空）；`stats` 支持至 6 项并自动调宽、按项数降字号；`style.imageFit:"cover"` 自动按目标框居中裁切并加圆角（超 1600px 自动缩放，结果缓存于系统临时目录）；`autoTitleSize`（默认开）按中英文字宽估算，超长标题自动缩字号，下限为基准的 60%。

## 已知限制

- 模板页面自动分类不可靠：照片墙、多组装饰字的复杂页面会被自动选作样板页；建议用 `samplePages` 手动指定。
- 文字改写可能错位或溢出：标题过长会覆盖其他元素，正文块替换顺序与视觉顺序可能不一致。注意 `autoTitleSize` 只作用于自由版式标题，模板模式的改写路径未覆盖。
- 模板图片保留：新内容主题与模板图片可能不匹配，需要事后替换。
- 模板字体缺失：渲染会返回缺失字体清单（如思源黑体、演示镇魂行楷），用户需自行安装字体才能还原设计。
- 模板库上传 UI 未实现，当前通过 `template-add` 导入。
- 设置页视觉效果未目视验证（无浏览器控制）。

## 下一步

1. 设置页模板库上传 UI。
2. 页面分类与文字换写的稳健性（按占位符/字号分档、文字溢出检测）。
3. 缺失字体提示与安装引导。
