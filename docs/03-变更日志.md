# 变更日志

## 2026-11-07（v0.1.2）

修复双栏版式「大空壳」：卡片高度硬编码 4.85 英寸，内容少时下方留出大片空白。改动在 `python/build.py`，改前备份为 `python/build.py.bak-20261107-142346`。

- 新增 `_bullets_height()`：按 `add_bullets()` 的真实排版参数建模（`line_spacing=1.18`、`space_after=0.55×字号`、悬挂缩进 0.34/0.82、可用宽度扣除缩进），估算一段 bullet 列表的渲染高度。
- `two_column_slide()`：卡片高度改为「两侧内容所需高度的较大值 + 0.85 顶距 + 0.35 底距」，下限 1.6 英寸、上限 4.85；整组在标题下方 1.6–6.45 区间内垂直居中，左右严格等高。
- 验证：3+3 条时卡片 4.85→**2.77**，5+5 条 3.00，1+1 条收到下限 1.60；三种情况卡片中心均精确落在 4.03（区间中点）。重建本套 16 页后，P4 卡片 3.13、P14 卡片 2.64，均贴合内容。

## 2026-11-06（v0.1.1 内部修订）

修复三处会污染成品的英文模板固件，并补齐两项易踩坑能力。改动集中在 `python/build.py`，改前备份为 `python/build.py.bak-20261106-121026`。

**硬编码文案清除**
- `_chrome_footer()`：页脚 `"PPT FORGE"` 改为读 `style.footerText`，默认为空即不输出；`showFooter` 默认由 `true` 改为 `false`。
- `cover_slide()`：封面 `"BUSINESS REPORT"` 改为 `style.coverEyebrow` / `spec.eyebrow`，`"PRESENTATION"` 改为 `style.coverBadge` / `spec.badge`，默认均为空即不输出。
- 影响：此前必须用 python-pptx 二次后处理删除这三行，现在开箱即净。

**stats 版式扩展**
- `stats_slide()`：条目上限由 `[:4]` 放宽到 `[:6]`；4 项以上自动缩小间距与卡片宽度，value/label 字号按项数分级（5 项 30pt、6 项 25pt）。
- value 文本按字符宽度动态降字号，避免长值（如 `8.6万→6000`）溢出卡片。

**图片自动处理**
- 新增 `_prepare_image()`：按目标框宽高比居中裁切、加圆角、超过 1600px 自动缩放，结果写入系统临时目录 `ppt-forge-imgcache` 并按路径哈希缓存。
- `add_picture_area()` 新增 `style.imageFit = "cover"` 分支启用上述处理；默认仍为 `"contain"`（完整显示不裁切），保持旧行为不变。

**标题防溢出**
- 新增 `_text_units()` / `_auto_title_size()`：按中英文字宽估算标题实际占用宽度，超出一行容量时按比例缩小字号，下限为基准字号的 60%。
- `_page_title()` 在 `style.autoTitleSize`（默认 true）开启时自动调用。

**验证**：5 页测试稿（封面 + 31 字长标题 + 5 项 stats + cover 裁切圆角图 + 页脚页）实测：无英文固件残留、stats 5 项全显示、长标题自动降至 24.23pt 且单行、图片圆角裁切生效、嵌入媒体为处理后的 PNG。

## 2026-11-04

- 新增模板模式：复制模板页面并改写文字（`python/template_engine.py`），支持 `template` 路径与 `templateName` 库引用、`samplePages` 手动指定样板页。
- 新增模板库：`template-add` 导入 .pptx、`template-list` 列出，存储于 `ppt-forge-library/templates/`。
- 新增渲染验收：`build` 的 `render` 选项与独立 `render` 动作（LibreOffice Kit），输出项目 `preview/` PNG 与缺失字体清单。
- 产物改为项目文件夹（`deck.pptx` + `preview/`）；`output` 指定 `.pptx` 时保持单文件输出。
- `learn` 改进：过滤模板占位文字，识别目录页与结尾页，优化标题与要点开头统计。
- 新增 `assets`：从样本提取背景/装饰图并生成 manifest。
- 设置页说明更新：多份样本学习、模板与图片能力。
- README 新增《PPT 制作经验》11 条：模板本质、自动套用边界、参考材料价值、使用要点。
