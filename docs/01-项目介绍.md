# PPT 工坊（@local/ppt-forge）

DSH Web GUI 插件 + Agent 工具：读取现成 PPTX 内容、学习样本风格、按模板生成新演示文稿。

## 能力

| 动作 | 作用 |
| --- | --- |
| `extract` | 读取一个 pptx 的每页文字、表格、备注 |
| `learn` | 批量分析样本，生成风格档案（JSON + Markdown） |
| `assets` | 提取样本里的背景/装饰图，建立素材库 |
| `template-add` / `template-list` | 导入 / 列出本地模板库 |
| `build` | 生成 pptx：自由版式，或按模板复制页面并改写文字 |
| `build` + `render: true` | 生成后自动渲染预览图并返回清单 |
| `render` | 单独把 deck 渲染为 PNG 预览 |

## 组成

- `index.js`：Host 工具、HTTP 路由（设置页状态查询、历史列表）
- `client.js`：设置页「PPT 工坊」
- `python/extract.py`：解析 pptx 结构
- `python/build.py`：自由版式生成（内置主题与版式）
- `python/template_engine.py`：模板页面复制与文字改写
- `python/learn.py`：样本风格分析
- `python/extract_assets.py`：背景/装饰素材提取

## 数据位置

- 风格档案与素材：`<工作目录>/ppt-forge-library/`
- 模板库：`<工作目录>/ppt-forge-library/templates/`
- 生成产物：`<工作目录>/ppt-forge-output/<标题-时间戳>/`
