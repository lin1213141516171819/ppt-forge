# 决策

## 插件形态
- Web GUI 插件（设置页入口）+ Agent 工具（主要使用方式）。
- 通过 profile 安装为 `@local/ppt-forge`。

## 数据与输出
- 数据来源：用户喂入的 `.pptx`（读取文字与结构）。
- 输出：原生 `.pptx`，可在 PowerPoint / WPS 继续编辑。

## 模板模式
- 显式启用：只有传 `template`（路径）或 `templateName`（库内名称）才走模板模式，否则使用自由版式。
- 模板来源：本地路径 + 模板库（`template-add` 导入）。
- 页面策略：复制模板页面并改写文字。模板的视觉设计在页面形状里，母版/版式只有占位符，不能靠继承还原设计。
- 页面类型：`cover` / `toc` / `section` / `content` / `end`，自动分类；`samplePages` 支持手动指定（1-based）。
- `style` 在模板模式下只保留结构参数（字号、页码、页脚等），`palette` 不生效，颜色以模板为准。
- 模板没有可用页面时自动降级为自由版式。

## 渲染验收
- `build` 支持 `render: true`，生成后自动渲染到项目 `preview/` 并返回图片清单与缺失字体。
- 独立 `render` 动作可对任意 deck 复检。
- 程序返回：页数、预览图、缺失字体；文字溢出与排版问题由 agent 看渲染图判断。
- 修正由 agent 主导（改大纲 / 改 style / 重新生成），不做程序自动改字。

## 产物
- 默认输出项目文件夹：`ppt-forge-output/<标题-时间戳>/deck.pptx + preview/`。
- `output` 显式指向 `.pptx` 文件时保持单文件输出（兼容旧用法）。

## 项目管理
- 四文档位于 `docs/`：项目介绍、决策、变更日志、当前状态与下一步。
- 文档只写当前状态，不保留过程性描述。
